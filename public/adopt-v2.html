Adopt A Mentor

Connecting new adopters with experienced pet parents — so no one has to figure it out alone.

UX / UI Designer

Overview

"Adopting a pet for the first time is overwhelming. AdoptMe asked me to design a feature that connects new adopters with experienced mentors — so no one has to figure it out alone."

The Problem

There's no one to ask.

New adopters have a lot of questions — the kind that aren't serious enough to call a vet, but too important to ignore. That gap creates frustration and loneliness at exactly the moment people need support most.

Information Gap
Questions too minor for a vet but too important to ignore — left completely unanswered.
Emotional Overload
New adopters are overwhelmed and anxious — they need empathy, not just instructions.
No Community
Experienced owners want to help — but there's no platform connecting them to those who need it.

How Might We

How might we give adopters guidance, emotional support, and practical advice from experienced pet owners?

Main Goals

What we set out to do

#1
Create guidance for adopters
A clear, structured path with human support at every step.
#2
Reduce anxiety in early adoption
Reduce confusion and overwhelm in the critical first weeks.
#3
Build community engagement
Connect experienced owners to those who need them — creating mutual value.

User Personas

Two sides of the same connection

Two users with opposite relationships to the process — one is looking for help, one is offering it. That asymmetry shaped every design decision.

Version 01

Automatic matching & simple web registration

A web-based registration form for each user type, with the system handling all the matching automatically.

V1 — How it worked

The brief, executed simply

Following the company's brief, I designed a straightforward registration flow — a form for each user type, with the system automatically matching adopters to mentors based on location. The mentor would then review the request and approve it.

Landing Page

User selection flow that directs mentors and adopters through the relevant registration process.

New Adopter Registration

Form collects key pet details — type, age, size — to understand the adopter's situation.

Mentor Match Proposal

Mentor receives adopter's profile and can accept the match — then receives their WhatsApp contact.

Design Reflection

What V1 taught me

Key Insight

Long web forms create friction — a pattern well-documented in onboarding research and something I experienced firsthand as a user. The system-controlled matching also removed agency from both sides of the connection.

The redesign focused on two things: making registration feel effortless, and shifting the power of matching from the system to the people.

Version 02

Mobile-first, interactive registration & community matching

A complete rethink — moving to mobile, replacing text fields with visual tiles, and giving users full control over matching.

Design Decisions

Every change, explained

Decision 01

Visual tiles instead of text fields

Replacing open text fields with visual selectors makes the process faster and more engaging — users tap instead of type. Less friction, same information.

Decision 02

Two steps instead of one long form

Splitting registration into personal details first, pet details second — each screen feels contained and manageable. Users don't see the full length upfront, reducing drop-off.

Decision 03

People-powered matching

Shifting matching control from an algorithm to the mentors themselves — they review adopter context and choose to accept. More intentional, more meaningful connections.

Key Screens

The full V2 flow

Each step is a separate screen — keeps users focused and reduces drop-off at every stage of the registration journey.

Reflection

Designing for Connection, Trust & First Steps

This project taught me that the biggest UX problems aren't always visible in the interface — sometimes they're in the assumptions. V1 assumed the system should control matching. V2 trusted the people. That shift made all the difference.
